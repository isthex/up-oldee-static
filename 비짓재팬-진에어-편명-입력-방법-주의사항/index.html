비짓재팬 진에어 편명 입력 방법 주의사항

발행: 2026-01-22

일본 여행을 준비할 때, 특히 비짓재팬(Visit Japan Web) 시스템에 진에어 편명을 정확하게 입력하는 방법에 대해 궁금해하는 분들이 많습니다. 비짓재팬 진에어 편명은 일본 입국 절차에서 매우 중요한 요소로, 온라인 사전 등록 시 항공편 정보를 올바르게 기입해야 입국 심사가 원활하게 진행됩니다. 이번 글에서는 비짓재팬 진에어 편명 입력법과 함께 아시아나, 에어부산 등 다른 항공사의 편명 입력법도 함께 살펴보고, 실제 사례와 최신 정보를 반영하여 비짓재팬 등록 과정을 쉽고 정확하게 이해할 수 있도록 설명하겠습니다.

비짓재팬 진에어 편명이란 무엇인가?

비짓재팬에서 요구하는 진에어 편명은 일본 입국 신고서 작성 시 항공편을 구분하기 위해 사용하는 항공편 번호입니다. 진에어 항공편은 “LJ”라는 항공사 코드와 3~4자리 숫자가 조합된 형태로 나타나는데, 비짓재팬 등록 시에는 항공사 코드는 선택란에서 “LJ”를 고르고, 숫자 부분만 따로 입력합니다. 예를 들어, 진에어 LJ211편을 탔다면, 항공사 코드는 ‘LJ’로, 편명 숫자는 ‘211’만 입력하는 식입니다. 이처럼 편명 숫자만 입력하는 이유는 비짓재팬 시스템이 항공사 코드와 숫자를 분리해서 관리하기 때문입니다.

실제로 비짓재팬 웹사이트와 일본 입국 신고서 작성 화면에서 편명 입력란은 숫자만 받도록 설계되어 있어, ‘LJ211’ 전체를 입력하면 오류가 발생할 수 있습니다. 따라서 티켓이나 모바일 항공권에 표시된 편명 중 숫자 부분만 참고하는 게 가장 정확합니다. 또한, 편명은 출발 항공편과 귀국 항공편 각각 별도로 입력해야 하기 때문에, 왕복 티켓을 가진 경우 두 편명을 모두 정확히 확인해야 합니다.

비짓재팬 진에어 편명 입력 방법과 주의사항

진에어를 포함한 저비용항공사의 비짓재팬 편명 입력 방법은 크게 다르지 않지만, 몇 가지 주의해야 할 점이 있습니다. 우선, 비짓재팬 등록은 출발 하루 전까지 완료하는 것이 좋습니다. 공항 현장에서도 가능하지만, 미리 준비해두면 입국 심사 시 시간을 단축할 수 있습니다. 진에어 편명을 입력할 때는 반드시 ‘LJ’ 항공사 코드를 선택하고, 뒤에 나오는 숫자만 입력하는 것을 기억해야 합니다.

또한, 편명 숫자를 입력할 때는 티켓에 적힌 그대로 입력하는 것이 중요합니다. 예를 들어, 티켓에 ‘LJ0341’로 표기되어 있어도 비짓재팬에는 ‘341’로 입력해야 하며, 앞의 ‘0’은 생략하는 경우가 많지만, 이 부분은 항공사별로 다를 수 있으므로 모바일 항공권에서 확인하는 게 가장 안전합니다. 만약 공동운항 편일 경우, 실제 탑승 항공사에 맞춰 편명을 입력하는 것이 일반적입니다. 예를 들어, 대한항공과 진에어 공동운항편이라도 진에어 항공기를 이용한다면 ‘LJ’ 편명을 등록하는 것이 맞습니다.

아울러, 편명 외에도 입국 신고서에는 도도부현, 전화번호, 우편번호 등 다양한 정보를 입력해야 하므로, 비짓재팬 웹사이트의 안내를 꼼꼼히 따라야 합니다. 특히 동반가족이 있을 경우, 각자 편명을 정확히 입력해야 하므로 가족 단위 여행객은 사전에 항공권 정보를 모두 체크하는 것이 좋습니다.

비짓재팬 진에어 편명 입력 절차

  • 비짓재팬 웹사이트 접속 후 일본 입국 신고서 작성 메뉴 선택
  • 항공사 코드 목록에서 ‘LJ’ 진에어 선택
  • 티켓 또는 모바일 항공권에서 편명 숫자 부분 확인 (예: 211, 341 등)
  • 숫자만 입력란에 정확히 입력
  • 왕복인 경우 출발편과 귀국편 각각 등록
  • 기타 개인정보(전화번호, 주소 등) 작성 후 등록 완료

편명 입력 시 흔히 발생하는 실수와 해결법

가장 흔한 실수는 항공사 코드까지 함께 입력하거나, 편명 숫자를 잘못 입력하는 경우입니다. 예를 들어, ‘LJ211’을 ‘LJ211’ 그대로 입력하면 오류가 발생합니다. 반드시 ‘211’만 입력해야 하며, 숫자 앞의 ‘0’을 빼야 하는지 고민될 때는 티켓에 표기된 대로 입력하되, 시스템에서 오류가 나면 한 번 ‘0’을 제거해 시도해보는 방법도 있습니다. 또한, 공동운항편의 경우 실제 탑승 항공사 편명을 확인하는 것이 중요합니다. 이 부분이 혼동될 경우 비짓재팬 고객센터나 항공사에 문의하는 것이 안전합니다.

아시아나, 에어부산 등 주요 항공사 편명 입력법 비교

비짓재팬 진에어 편명 입력법을 이해했다면, 아시아나(OZ), 에어부산(BX), 제주항공(7C) 등 다른 항공사 편명 입력법도 함께 알아두는 것이 좋습니다. 모든 항공사는 비짓재팬에서 항공사 코드(영문 2자리)를 선택하고, 편명 숫자만 입력하는 방식입니다. 단, 제주항공처럼 ‘7C’처럼 숫자가 아닌 코드가 포함된 경우에도 코드 선택 후 숫자만 입력하는 방식이 동일합니다.

항공사 항공사 코드 비짓재팬 편명 입력 방법
진에어 LJ ‘LJ’ 선택 후 편명 숫자만 입력 (예: LJ211 → 211)
아시아나항공 OZ ‘OZ’ 선택 후 편명 숫자만 입력 (예: OZ123 → 123)
에어부산 BX ‘BX’ 선택 후 편명 숫자만 입력 (예: BX456 → 456)
제주항공 7C ‘7C’ 선택 후 편명 숫자만 입력 (예: 7C789 → 789)

위 표에서 보듯, 모든 항공사는 코드 선택 후 편명 숫자만 입력하는 방식으로 통일되어 있어, 비짓재팬 진에어 편명뿐 아니라 다른 항공사 편명도 큰 어려움 없이 등록할 수 있습니다. 다만, 항공권 예약 시 받은 이티켓이나 모바일 항공권에서 편명 숫자를 반드시 확인하는 습관이 중요합니다.

비짓재팬 진에어 편명 등록 시 실제 경험과 팁

실제로 일본 여행을 다녀온 분들의 경험을 살펴보면, 비짓재팬 진에어 편명을 정확히 입력하지 않아 입국 심사에서 잠시 질문을 받거나 수정하는 경우가 종종 있습니다. 예를 들어, 한 여행객은 티켓에 ‘LJ0341’로 표기된 편명을 ‘LJ0341’ 그대로 입력해 오류가 났고, ‘341’로 수정 후 문제가 해결된 사례가 있습니다. 또한, 출발과 귀국 항공편이 다를 때 각각 편명을 별도로 등록하지 않아 혼란이 발생한 경험도 있습니다.

이러한 문제를 피하기 위해서는 반드시 출국 전 비짓재팬 웹사이트에서 본인의 편명을 확인하고, 편도별로 각각 등록하는 것이 중요합니다. 그리고 가족 단위로 여행할 때는 동반 가족 모두의 편명도 정확히 입력해야 하므로, 항공권을 함께 확인하는 절차가 필요합니다. 만약 공동운항편이라면 실제 탑승하는 항공사 편명을 기준으로 등록해야 하며, 변경사항이 있을 경우 비짓재팬에서 편명을 빠르게 수정하는 것이 입국 절차를 원활하게 하는 데 도움이 됩니다.

자주 묻는 질문

비짓재팬에 진에어 편명을 입력할 때 ‘LJ’ 코드도 같이 써야 하나요?

비짓재팬 진에어 편명 입력 시에는 항공사 코드 ‘LJ’를 선택란에서 선택하고, 편명 입력란에는 숫자만 입력하면 됩니다. 예를 들어, 진에어 편명이 LJ211이라면 숫자 ‘211’만 입력하는 것이 맞습니다. ‘LJ211’ 전체를 입력하면 시스템 오류가 발생할 수 있으니 주의해야 합니다.

진에어와 다른 항공사 공동운항편이라면 어떤 편명을 입력해야 하나요?

공동운항편이라도 실제 탑승하는 항공사 편명을 기준으로 비짓재팬에 등록하는 것이 일반적입니다. 예를 들어 대한항공과 진에어 공동운항편에서 진에어 항공기를 이용한다면, 진에어 ‘LJ’ 편명을 입력하는 것이 맞습니다. 다만, 불확실한 경우 항공사에 문의하거나 비짓재팬 고객센터에 확인하는 것이 안전합니다.
